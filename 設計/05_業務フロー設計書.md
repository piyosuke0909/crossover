# 業務フロー設計書

## 1. 新規参加企業

1. 管理者が交流会を作成
2. システムが交流会URLを発行
3. URLからQRコードを作成
4. 会場にQRコードを設置
5. 参加者がQRコードを読み取る
6. 新規登録を選択
7. 企業情報を入力
8. 担当者情報を入力
9. 顔写真を登録
10. 登録完了
11. 交流会参加企業一覧へ表示

## 2. 既存企業の次回参加

1. 参加者が新しい交流会のQRコードを読み取る
2. 登録済み企業を選択
3. 再登録キーを入力
4. 既存企業情報を呼び出す
5. 今回参加する担当者を選択
6. 必要であれば新しい担当者を追加
7. 今回の交流会に参加登録
8. 参加企業一覧へ表示

## 3. プロフィール編集

1. 編集画面へ移動
2. 再登録キーまたは編集キーを入力
3. 企業・担当者情報を編集
4. 保存
5. 一覧・詳細画面へ反映

## 4. 管理者

1. 管理画面へログイン
2. 交流会を作成
3. QRコードを発行
4. 登録状況を確認
5. 必要に応じて企業・担当者を非表示
6. 終了後に企業一覧・参加者名簿CSVを出力
