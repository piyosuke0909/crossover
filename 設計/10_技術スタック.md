# 技術スタック

- Next.js 16.3.8
- React 19.3
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM 7
- Vercel Blob（Public）
- Vercel

## 構成方針

MVPではフロントエンドとバックエンドを分離せず、Next.js App Routerで構築する。

スマートフォンからの利用を中心とし、PCでも利用できるレスポンシブWebアプリケーションとする。

## PostgreSQL / Prisma

企業、担当者、交流会、参加情報はPostgreSQLで管理する。

Prisma Clientは app/generated/prisma に生成し、生成物はGit管理しない。

主なモデル:

- Company
- Person
- Industry
- Event
- EventCompany
- EventPerson
- CompanyAccessKey

## Vercel Blob

担当者の顔写真はVercel BlobのPublic Storeへ保存する。

PostgreSQLには画像本体ではなくBlob URLをPerson.photoUrlとして保存する。

アップロード方式はClient Uploadとする。

制限:

- JPEG
- PNG
- WebP
- 最大5MB
- ランダムサフィックス付与
