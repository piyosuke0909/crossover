# DB設計書

## 1. エンティティ

### Company
企業情報。

主な項目:
- id
- name
- phone
- postal_code
- address
- website_url
- industry_id
- business_description
- profile
- is_hidden
- created_at
- updated_at

### Person
担当者情報。

主な項目:
- id
- company_id
- name
- photo_url
- department
- position
- phone
- responsibility
- profile
- is_hidden
- created_at
- updated_at

### Industry
業界マスタ。

主な項目:
- id
- name
- created_by_user
- is_active
- created_at

### Event
交流会情報。

主な項目:
- id
- name
- event_date
- venue
- description
- public_slug
- created_at
- updated_at

### EventCompany
交流会と参加企業の中間テーブル。

主な項目:
- id
- event_id
- company_id
- joined_at

### EventPerson
交流会と参加担当者の中間テーブル。

主な項目:
- id
- event_id
- person_id
- joined_at

### CompanyAccessKey
企業プロフィール再利用・編集用キー。

主な項目:
- id
- company_id
- key_hash
- created_at
- revoked_at

## 2. リレーション

- Company 1 : N Person
- Industry 1 : N Company
- Event N : N Company
- Event N : N Person
- Company 1 : N CompanyAccessKey

## 3. 削除方針

企業・担当者は論理削除または非表示フラグで管理する。

過去のイベント参加履歴は保持する。
