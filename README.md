# Crossover 企業交流会 Webシステム

犬山で開催される「クロスオーバー」企業交流会向けのWebシステムです。

会場のQRコードから参加者が企業・担当者プロフィールを登録し、参加企業を検索・閲覧できる仕組みを提供します。

## MVPの目的

- 交流会に「どの企業・担当者が参加しているか」を分かるようにする
- 参加企業の事業内容・プロフィールを確認できるようにする
- 企業名・キーワード・業界から探せるようにする
- 交流会ごとに参加企業・担当者を管理する
- 管理者が企業一覧・参加者名簿をCSV出力できるようにする

## 主な機能

### 参加者側
- QRコードから交流会ページへアクセス
- 企業プロフィール登録
- 担当者プロフィール登録
- 担当者顔写真登録（必須）
- 企業情報・担当者情報の後編集
- 企業名検索
- キーワード検索
- 業界フィルター
- 参加企業一覧
- 企業詳細・担当者詳細の閲覧
- 交流会終了後も同じURLから閲覧

### 管理者側
- 管理者ログイン
- 交流会作成・編集
- 交流会URL / QRコード発行
- 登録企業・担当者管理
- 企業・担当者の非表示
- 企業一覧CSV出力
- 参加者名簿CSV出力

## MVP対象外

- チャット / DM
- 名刺スキャン
- AIマッチング
- お気に入り
- SNS・フォロー機能
- 高度な分析
